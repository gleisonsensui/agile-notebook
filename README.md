# Agile Notebook

> Um repositório de estudos, pesquisa aplicada e experimentação sobre Gestão Ágil, Lean, Produto, Liderança, Coaching e Transformação Organizacional.

## 📖 Objetivo

O **Agile Notebook** é um repositório dedicado à construção de conhecimento estruturado sobre Gestão Ágil de Projetos, Produtos e Organizações.

Mais do que um simples conjunto de anotações, este projeto busca consolidar conceitos, práticas, frameworks, modelos mentais e evidências que permitam compreender a Agilidade de forma crítica, sistêmica e baseada em fundamentos sólidos.

O objetivo é evoluir continuamente do entendimento dos princípios fundamentais até temas avançados como transformação organizacional, liderança ágil, métricas de fluxo, coaching, escalabilidade e arquitetura organizacional.

Ao longo do tempo, este repositório servirá como uma base de conhecimento viva, reunindo aprendizados obtidos por meio de estudos, livros, artigos científicos, experimentos, casos reais e experiências práticas.

---

# 🎯 Missão

Construir uma base de conhecimento consistente que permita compreender:

- os fundamentos da Agilidade;
- os diferentes frameworks ágeis;
- Lean Thinking;
- Gestão de Produto;
- Business Analysis;
- Gestão de Fluxo;
- Engenharia Organizacional;
- Coaching e Facilitação;
- Transformação Organizacional.

Sempre buscando responder duas perguntas fundamentais:

> **Por que determinada prática existe?**

e

> **Em qual contexto ela gera maior valor?**

---

# 🚀 Visão

Este repositório faz parte de um conjunto maior de notebooks de engenharia de software e gestão tecnológica.

Sua finalidade é apoiar o desenvolvimento de profissionais capazes de compreender a Agilidade como um sistema adaptativo complexo, e não apenas como a aplicação mecânica de frameworks.

No longo prazo, este conhecimento servirá como base para pesquisa, validação e evolução do **Agile Discovery Framework (ADF)**, um framework voltado à descoberta, planejamento e condução de iniciativas ágeis fundamentadas em princípios, evidências e melhoria contínua.

---

# 🧠 Filosofia

Este projeto parte dos seguintes princípios:

- Agilidade não é um conjunto de cerimônias.
- Frameworks são ferramentas, não objetivos.
- Não existem soluções universais.
- Todo contexto exige adaptação.
- Decisões devem ser orientadas por evidências.
- Pessoas e sistemas evoluem continuamente.
- O aprendizado é incremental.
- Toda prática deve possuir um propósito claro.

# 🔬 Metodologia de Estudo

O conhecimento é organizado de forma incremental.

Cada módulo procura responder às seguintes perguntas:

1. O que é?
2. Qual problema resolve?
3. Como funciona?
4. Quando utilizar?
5. Quando não utilizar?
6. Quais vantagens?
7. Quais limitações?
8. Como aplicar?
9. Como medir resultados?
10. Quais são os principais erros?
11. Como se relaciona com outros conceitos?

Essa abordagem permite construir uma compreensão progressiva e integrada dos diferentes aspectos da Gestão Ágil.
